Opérateur d'affectation

En langage C l'opérateur d'affectation est l'opérateur =. Il posséde une associativité de droite à gauche.

Ex: int i = j = k = 1;

Opérateur d'incrémentation et de décrèmentation

Les affectations les plus fréquents sont de types i = i + 1 ou i = i - 1.

En langage C nous disposons de 2 opérateurs inhabituels

Algo C
i = i + 1 i++ ou ++i(incrémentation) augmentation d'une unité
i = i - 1 i-- ou --i(decrementation) diminution d'une unité

L'opérateur ++ et -- sont employées dans les suivants:

incrémentation ou Décrémenter
une variable par exemple dans une boucle, dans ce cas il n'y a pas de différence entre le notation préfixe (++i et --i) et postfixe (i++ et i--)
incrémentation ou Décrémenter
une variable est en même temps affectée sa valeur à une autre variable dans ce cas nous devons choisir entre la notation préfixe (++i et --i) et postfixe (i++ et i--)

x = i++; // On passe d' aborde la valeur de i à X et on incrémente i après

ex: x = i++ où i = 4, ⇛ x = 4 et i = 5

x = ++i; // On incrémente d'abord la valeur de i et on passe cette valeur incrémenté à x

ex: x = ++i où i = 4, x = 5

x = i--; // on passe d'aborde la valeur de i et on décrémente i après.

ex: x = i-- où i = 4, ⇛ x = 4 et i = 3

x = --i; // On décrémente d'abord la valeur de i et on passe cette valeur décrémenté à x

ex: x = --i où i = 4, ⇒ x = 3 et i = 3

Priorité des opérateur

En langage C l'ordre Priorité des opérateurs est le suivant

Priorité
1 (la plus forte) ()
2 ! ++ --
3 * / %
4 + -
5 < <= > >=
6 == !=
7 &&
8 ||
9 = += /= *= %=

Dans chaque classe de priorité, les opérateurs ont la même priorité. Si nous avons une suite d'opérateur binaire dans la même classe l'évaluation se de la gauche vers la droite dans l'expression.

Pour les opérateurs unaires (++ -- !) et pour les opérateurs d'affectation, l'évaluation se fait à gauche dans l'expression.

Conversion implicite de type

Dans une manière générale, on peut dire que si un opérateur porte sur 2 opérandes différentes (type ≠), il y a en quelque sorte conversion du type le plus faible en type le plus fort.

        long p, q;
        int r;
        p = r + q; // r → long

Conversion de type explicite

Si on souhaite forcer la conversion d'une expression quelconque dans un type de votre choix, on peut utiliser l'opérateur cast

        int a, b;
        float x;
        x = (float) a/b; // x = 2.5
