Les sorties

Pour afficher un caractère ou une chaîne de caractère à l'écran il faut utiliser des fonctions de la bibliothèque stio.h il éxiste 3 fonctions d'affichage de données en langage C

La fonction printf

La fonction printf permet non seulement d'afficher des caractere, des chaines de caractère pour le formatage du texte mais egalement la valeur d'une variable passe en parametre

Ce faire, il suffit d'utiliser un indicateur de conversion % suivit d'une < lettre > qui varie en fonction du type de la valeur

Type de variable Indicateur de conversion
Char %c
short %hd
int %d
long %ld
float %f
double %f ou %lf
longdouble %lf
unsigned short %hu
unsigned int %u
unsigned long %lu 
            ex: int nb1 = 10, nb2 = 200;
                float x = 12,35
                char lettre = 'x';
                printf("Nombre = %d, nombre = %d, flottant = %f et lettre = %c\n", nb1, nb2, x, lettre);

Remarques:

On peut afficher toutes sortes d'operation elemetaire a l'interieur de printf

            ex: printf("X=%f\n", (float) -b/a);

Lorsqu'on affiche un flottant; il y a un certain nombre de zero qui suive et ce peu importe qu'ils sont utile ou non. Afin de supprimer certain zero inutil en procede comme suit:

On met un point apres l'indicateur de conversion % suivit par un nombre qui indique le nombre de chiffre qu'if aura apres la virgule et enfin la lettre qui indique le type de la variable. 

        Ex: printf("x = %f\n", (float) -b/a);
            ⇛ //x = -2,5000
           printf("x = %.2f\n", (float) -b/a);
             ⇛ //x = -2,50

             printf("x = %d\n",x);
             printf("x = %.2f\n",);
             ⇛ //x = -2,50

La fonction putchar

Permet d'ecrire un seul caractère

        Ex: putchar('x');               print("x");
            char lettre = 'x'; ≡  char lettre = 'x';
            putchar(lettre);             print("%c", lettre);
