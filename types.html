Les types de bases en langage C se répartie en 3 grandes catégories:

  • Nombres entiers
  • Nombres flottant ou à virgule
  • Caractère (variable)

Les types entiers

Le langage C prévoit que sur une machine on puisse trouver 3 tailles d'entier: short, int et long.
Par défaut, le type entier est signé c'est-à-dire qu'il peut prendre la valeur négative, nulle et positive(−, Ø, +).
Chacun des trois types entiers peut être nuancer par l'utilisation qualificative unsigned ou type non signé. Dans ce cas, on ne représente plus que le nombre positif +

Les nombres flottants

Les nombres flottant permettent de représenter d'une manière approche le nombre réel. Le langage C prévoit trois types flottants: float, double, et longdouble.

  • La notation décimale: elle doit obligatoirement comporter un point .
  • La notation exponnentielle: elle utilise la lettre ∥E ) majuscule pour introduire un exposant entier puissance de 10 avec ou sans signe (−, +).
Algo C
Décimale 12,34 12.34
Exponnentielle 12.10 3 12E3

Les types caractère

Les constantes sont de types caractère lorsqu'elle correspond à des caractères imprimables c'est-à-dire, à des caractères que l'on peut Afficher.

Certain caractère non-imprimable possède une représentation conventionnelle utilisant le caractère backslah ou antislah suivit d'une lettre \< lettre >

Notation en C Signification
\a cloche ou bip
\b backspace
\f saut de page
\n saut de ligne
\v tabulation verticale
\t tabulation horizontale
