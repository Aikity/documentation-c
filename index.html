Introduction

Le langage C est un langage compilé, c'est-à-dire :

- Qu'il faut entrer un texte dans l'ordinateur à l'aide d'un éditeur (Vs Code, Notepad++, Bloc note, etc.)

- Qu'il faut le traduire en langage machine, c'est-à-dire en code binaire, à l'aide d'un compilateur (mingW)

- Qu'il faut l'exécuter

Structure d'un programme en langage C

Directive de préprocesseur(ou bibliothèque) commençant par # et se terminant par un retour à la ligne (pas de point-virgule).

Les déclarations globales qui se terminent par un point-virgule.

Les suites de fonctions écrites les unes après les autres.

Certaines bibliothèques sont incluses dans les ordinateurs, ce qui permet au programme de s'exécuter.

Pour ajouter une bibliothèque, on utilise la syntaxe suivante :

#include <nom_bibliothèque>

Voici un exemple en langage C qui affiche Bonjour à l'écran.

                
                                
#include <conio.h>

int main() {
    puts("Bonjour !!!");
    getch();
    return 0;
                
  
}

La valeur de retour n'est pas obligatoire si on utilise le mot-clé void à la place de int. Dans ce cas, on utilise return; à la place de return 0;

int main() {
    ...
    return 0;
}
void main() {
    ...
    return;
}
main() {
    ...
}

#include <stdio.h> : inclut l'entête standard contenant la déclaration des entrées et des sorties.

La fonction puts est un extrait de cette bibliothèque.

int est le type renvoyé par la fonction main().

main() : est la fonction principale du langage C.

getch() : est une fonction qui permet l'attente de la frappe d'une touche. C'est un extrait de la bibliothèque <conio.h>

Quelques règles d'écriture

Les identificateurs

Les identificateurs servent à désigner les différents objets manipulés par le programme :

  1. Les variables
  2. Les types
  3. Les fonctions

Ils sont formés par des caractères ou suites de caractères parmi les lettres et les chiffres.

Le premier d'entre eux est une lettre ; les majuscules et les minuscules sont autorisées mais ne sont pas équivalentes. On dit alors que le langage C est sensible à la casse (a ≠ A).

REMARQUE : tous les types et toutes les fonctions standard du langage C doivent être écrits en MINUSCULE.

Les séparateurs
Deux identificateurs consécutifs doivent être séparés par une fin de ligne ou un espace.
Les commentaires

// : sur une ligne.

/* ... */ : sur plusieurs lignes.
