Introduction

Le langage C est un langage compilé, c'est-à-dire

-Qu'il faut entrer un texte dans l'ordinateur à l'aide d'und éditeur (Vs Code, Notepad++, Bloc note, etc)

-Qu'il faut le traduire en langage machine c'est-à-dire en code binaire à l'aide d'un compilateur (mingW)

-Qu'il faut l'exécuter

Structure d'un programme en langage C

Directive de préprocesseur(ou bibliothèque) commençant par # et se termine par un retour à la ligne (pas de point virgule)

Les déclarations globales qui se terminent par un point virgule

Les suites de fonction écrites les unes après les autres

Certaine bibliothèque sont inclues dans des ordinateurs ce qui peremet au programme de s'exécuter.

Pour ajouter une bibliothèque, on utilise la syntaxe suivant: #include < nom_bibliothèque >

Voici un exemple en langage C qui affiche Bonjour à l'écran.

                    #include < stdio.h >
                    #include < conio.h >
                    int main () {
                        puts("Bonjour !!!");
                        getch();
                        return ø;
                    }

La valeur de retour n'est pas obligatoire se on utilise le mot clés void à la place de int. Dans ce cas, on utilise return; à la place de return ø; 

                     int main () {
                        ...
                        return ø;
                    } 
                
                     void main () {
                        ...
                        return;
                    } 
                
                     main () {
                        ...
                    }

#include < stdio.h >: inclus l'entête standart contenant la déclaration des entrées et des sorties.

La fonction puts est un extrait de cette bibliothèque.

int est le type renvoyer par la fonction main().

main():est la fonction principale pour le langage C

getch(): est une fonction qui permet l'attente de la frappe d'une touche. C'est un extrait de la bibliothèque < conio.h >

Quelques règles d'écriture

Les identificateurs
Les identificateurs servent à désigner les différents objets ,manipuler par le programme
  1. Les variables
  2. Les types
  3. Les fonctions
Ils sont formés par des caractère ou suite de caractère parmi les lettres et les chiffres.

Le premier d'entre eux est en une lettre, les majuscules et les miniscules sont autorisés mais ne sont pas équivalents. On dit alors que le langage C est sensible à la casse (a ≠ A)

REMARQUE: Tout les types toutes les fonctions standart du langage C doivent être écrite en MINUSCULE

Les séparateurs
Deux identificateurs consécutif doivent être séparer par une fin de ligne ou un espace.
